## Přístupnost (AUDIT sekce 4)

- **Ikonová tlačítka dostala `aria-label`:**
  - plovoucí tlačítko chatu (`LiveChatWidget`) → „Otevřít chat s AI asistentem" /
    „Zavřít chat" + `aria-expanded`
  - zavírací „X": `AIChatbot` → „Zavřít průvodce", `LiveChatWidget` → „Zavřít chat"
  - `Header` hamburger: `aria-label="Toggle mobile menu"` → „Otevřít menu" /
    „Zavřít menu" + `aria-expanded`
- **Chat `aria-live`:** kontejner zpráv v `LiveChatWidget` má `aria-live="polite"`
  → čtečka oznámí odpověď bota.
- **Skip-link:** `App.jsx` – první fokusovatelný prvek `<a href="#obsah">Přeskočit
  na obsah</a>` (`sr-only focus:not-sr-only`, tyrkysová pilulka vlevo nahoře).
  `id="obsah"` přidáno na `<main>` v `Home`, `ConnectPage`, `ServiceLanding`.
- **Viditelný fokus:** globální `:focus-visible { outline: 2px solid #0EC3BF }`
  v `index.css` – jen při navigaci klávesnicí.
- **Kontrast textu:** `text-gray-500` (~3,4:1, propadá WCAG AA) → `text-gray-400`
  (~5,9:1) tam, kde nese informaci: `Footer` (copyright + odkazy cookies),
  `Form` (fakturační údaje + „fyzická osoba…").
- **Hierarchie nadpisů:** „Nevíte si rady" v `Pricing` `h4` → `h3`; sloupcové
  nadpisy v `Footer` `h4` → `h2` (patička je vlastní landmark).
- **Externí odkazy `target="_blank"`** dostaly `aria-label` „(otevře se v novém
  okně)": GitHub + LinkedIn v `Footer` (navíc jim úplně chyběl přístupný název)
  a oba odkazy na projekt v `Reference` (dřív bezejmenné „Zobrazit projekt").
- **ESLint a11y:** přidán `eslint-plugin-jsx-a11y` (`flatConfigs.recommended`)
  do `eslint.config.js`. Po 2. dávce běží na plné přísnosti (`error`) –
  žádné výjimky, `npm run lint` je čistý.

### 2. dávka – přístupnost pokračování

- **`CustomSelect` → nativní `<select>`:** vlastní dropdown (nešel klávesnicí
  ani čtečkou) nahrazen stylovaným nativním `<select>` – `appearance-none`
  + vlastní tyrkysová šipka, `[&>option]` styly. Klávesnice / čtečka / mobilní
  UI fungují zadarmo. Props API beze změny, `Form.jsx` netknut. Ověřeno –
  a11y strom hlásí `combobox` se 4 `option`.
- **Chat modaly – dialog a11y:** nový `src/lib/useFocusTrap.js` (fokus dovnitř
  po otevření, Tab cyklí uvnitř, návrat fokusu na spouštěč po zavření).
  - `AIChatbot`: `role="dialog"` + `aria-modal="true"` + `aria-labelledby`,
    Esc zavírá, focus trap, `useBodyScrollLock`.
  - `LiveChatWidget`: `role="dialog"` + `aria-labelledby`, Esc zavírá, fokus
    do vstupu / zpět na plovoucí tlačítko. **Bez** `aria-modal`/scroll-locku/
    tvrdého trapu – je to plovoucí panel, zbytek stránky zůstává funkční.
  - Ověřeno v Chrome: oba se otevřou, Esc zavře.
- **`CookiePolicy` pozadí:** `<div onClick>` → `<button type="button"
  tabIndex={-1} aria-label>` (klik-mimo zavírá, klávesnici slouží Esc + „X").
  Tím odpadl poslední jsx-a11y warning → rules vráceny na `error`.
